# GoIT JavaScript Homework #10 (Module 10)

This project is the tenth JavaScript homework assignment within the GoIT Full Stack Developer program. It focuses on asynchronous JavaScript, timers (`setInterval`), date/time selection using **flatpickr**, notifications via **iziToast**, and advanced Promise management.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-js-hw-10/)

## 🛠️ Tasks Included
- **Task 1 (Countdown Timer):** A fully functioning countdown clock integrated with `flatpickr` for cross-platform future date selections, displaying remaining days, hours, minutes, and seconds formatted with leading zeros (`00`).
- **Task 2 (Promise Generator):** A notification generator form that accepts a millisecond delay and state options (fulfilled/rejected), returning a promise handled with custom `iziToast` feedback.

## 🛠️ Technologies & Tools Used
- **JavaScript (ES6+):** Asynchronous programming, Promises, timers, time calculation algorithms.
- **Bundler:** Vite.
- **External Libraries:** `flatpickr`, `iziToast` via NPM.
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
